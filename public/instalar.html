Windows — passo recomendado

Para o player abrir ao ligar o PC, baixe e execute o assistente abaixo (copia o atalho para a pasta Inicializar).

Iniciar o player com o Windows

Depois de executar o ficheiro .bat, clique em «Entrar com e-mail» abaixo. Manual: Win+R → shell:startup → arraste o atalho do Radio Ibiza.

Entrar com e-mail

Dica no Mac (Google Chrome)

O Chrome costuma deixar o atalho dentro de Apps do Chrome no Finder. Para o ícone aparecer junto dos outros programas, arraste o Player Radio Ibiza para a pasta Aplicativos.
