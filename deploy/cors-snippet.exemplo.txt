# =============================================================================
# CORS para PWA Radio Ibiza 4.x (Opcao A do roadmap)
# =============================================================================
# O backend CakePHP nao sera alterado. CORS entra na conversa quando o browser
# faz pedido entre origens diferentes (ex.: pagina em https://a.com e API
# em https://cloud.radioibiza.com.br).
#
# Hospedado no NETLIFY com o netlify.toml deste repo (cenario normal do projeto):
# O browser fala com a mesma origem do PWA: fetch vai para `/api/*` e
# redirects no Netlify encaminham para o cloud no servidor. O POST/GET ao
# webservice nao cruza origem no browser — nao precisas de CORS no Apache do
# cloud "so porque" este PWA esta neste host.
#
# MP3: em producao por defeito `url_musica` usa HTTPS directo aos hosts Radio Ibiza
# (envyron/cloud) — esse host deve enviar cabecalhos CORS para permitir fetch desde
# o dominio do PWA. Se algo falhar, o player faz fallback ao proxy same-origin
# (/ws-get_musica_cloud) no Netlify. Rollback codigo legado inteiro ao proxy só:
# env VITE_IBIZA_FORCE_GET_MUSICA_PROXY=1 na build Netlify (ver `.env.example`).
#
# Para NAO contar primeiro download grande na Netlify: depois de activar ACAO nos blocos em baixo,
# usar na build: VITE_IBIZA_PREFETCH_GET_MUSICA_CLOUD_DIRECT_FIRST=1 (detalhes em docs/MP3_PREFETCH_FORA_NETLIFY.md).
# Opcao infra sem mexer Neste servidor: ponta Cloudflare Workers (VITE_IBIZA_MP3_CORS_BRIDGE_ORIGIN).
# So precisas de CORS no Apache/Nginx do SOLO se:
#   (a) servires o PWA noutro host sem estes redirects, OU
#   (b) quiseres fetch direto ao cloud sem proxy (ex.: build sem Netlify).
#
# Substitua:
#   https://player.EXEMPLO.com.br   -> em producao: https://player4.radioibiza.com.br
# pelo dominio HTTPS real onde o `dist/` do Vite ficara hospedado.
#
# Preferir aplicar só em location especifica do get_musica (DigitalOcean / VPS):
#   /services/webservice/get_musica/
# Ver checklist ops + Netlify env em docs/CORS_GET_MUSICA_ATIVACAO.md
#
# IMPORTANTE:
# - PWA em producao precisa de HTTPS para Service Worker registrar.
# - Se PWA e webservice ficarem NO MESMO dominio/path, CORS pode ser desnecessario.
# =============================================================================
